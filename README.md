# All Blue 22

Build a 22-player football lineup from One Piece characters, then simulate a 17-game season.

**Play it:** https://allblue22.com

## Modes

- **Builder**: pick anyone for any spot. Switch between 3-4 and 4-3 defenses and Fullback or Slot offenses, filter by faction, and turn Legends on or off. Tap a spot to swap someone in, or drag one tag onto another.
- **17–0 Challenge**: each round rolls a faction and a Devil Fruit type. Draft a matching character into any open spot (up to 3 Legends, 2 rerolls of each). Fill all 22, then play the season.
- **Grand Line Draft**: each round rolls one random character. Place them anywhere (3 skips per run).

## How scoring works

Every character has rough 1–10 ratings for speed, strength, technique, smarts, toughness and size. Each position weights those differently, and size away from the position's ideal costs points. That gives a fit score out of 99.

The team score is the average fit, with QB, pass rushers and corners counting extra. Your four weakest spots drag it down. Opponents run from 350 (Loguetown) to 910 (Laugh Tale), and each game's win chance comes from the gap between the two scores.

## Player photos

Players show an original badge with their initials, faction color and Devil Fruit pattern. Players can add their own photos with the **Player photos** button. Name files after the character (`luffy.jpg`, `nico-robin.png`) to bulk-match them. Photos are resized and stored only in that visitor's browser. Nothing is uploaded to the site.

## Running it

It's one static file with no build step. Open `index.html` in a browser, or drop the folder on any static host (Netlify, Cloudflare Pages, GitHub Pages).
